③ 검토 — 사람이 결정하는 관문

④ 팩 — 승인된 지식만 내보내기

③에서 승인된 개념·관계만 모아 변경 불가능한 팩으로 만듭니다. 팩은 빌드한 순간의 스냅샷이라, 이후에 승인한 내용은 기존 팩에 자동 반영되지 않습니다 — 새 승인분이 생기면 새 이름으로 다시 빌드하세요. AI(MCP)는 이 팩만 읽을 수 있어서, 검증 안 된 내용이 새어 나가지 않습니다.

⑤ 연결 — AI에서 팩 사용하기 (MCP)

빌드된 팩을 Claude Desktop / Claude Code 같은 AI 도구에 연결합니다. 각 팩 카드의 연결 설정 복사를 눌러 나온 내용을 도구 설정에 붙여넣으면 끝입니다. AI는 팩을 읽기만 할 수 있습니다.

Claude Desktop에 붙여넣는 방법
  1. 아래 팩 카드에서 연결 설정 복사 (JSON) 클릭
  2. Claude Desktop → 설정 → 개발자 → 설정 편집으로 설정 파일 열기
  3. "mcpServers" 항목 안에 복사한 내용을 붙여넣고 저장
  4. Claude Desktop 재시작 — 대화에서 팩 내용을 물어보면 확인됩니다
