안녕하세요! 👋

ontologylab은 문서를 읽혀서 믿을 수 있는 지식으로 바꾸는 도구예요. AI가 초안을 만들고, 여기서 직접 승인한 것만 지식이 돼요. 아래 네 걸음이면 한 바퀴 다 돌아요 — 진행되는 만큼 체크가 켜져요.

1
문서 하나 넣어보기

뭐든 좋아요. 처음이면 준비된 샘플(우리 가게 주문 시스템 이야기)로 가볍게 시작해보세요.

2
AI에게 초안 맡기기

넣은 문서에서 개념과 관계를 뽑아 와요. 여기서 나온 건 아직 제안일 뿐이라 지식이 아니에요.

3
맞으면 승인, 아니면 거부

여기가 이 도구의 심장이에요. 직접 승인한 것만 지식으로 남아요 — AI는 절대 대신 결정하지 않아요.

4
승인한 지식을 팩으로 묶기

팩은 Claude 같은 AI에게 물려줄 수 있는 검증된 지식 상자예요.

🎉 한 바퀴 완주! 이제 에서 Claude에 물려주거나, 새 문서로 지식을 더 쌓아보세요.

모든 데이터는 이 컴퓨터에만 저장돼요. 연습용 데이터는 마음껏 만졌다가 언제든 지우고 다시 시작할 수 있어요.

③ 검토 — 직접 결정할 차례예요

여기서 승인한 것만 팩에 들어가요 · 크리틱 점수는 참고용, 결정은 항상 사용자 몫이에요

AI가 제안한 개념(노드)과 관계(엣지)를 하나씩 승인 또는 거부해요. 확신도가 낮은 항목부터 보여드려요 — 낮다고 틀린 게 아니라, 눈이 한 번 더 필요한 순서예요.

④ 팩 — 승인한 지식을 상자에 담아요

③에서 승인한 개념·관계만 모아 팩으로 만들어요. 팩은 만든 순간의 스냅샷이라, 나중에 승인한 건 자동으로 안 들어가요 — 새 승인분이 생기면 새 이름으로 다시 만들면 돼요. AI(MCP)는 이 팩만 읽을 수 있어서, 검증 안 된 내용은 절대 새어 나가지 않아요.

팩 빌드

다음 단계: 팩을 만들었다면

⑤ 연결 — Claude에게 지식을 물려줘요

만든 팩을 Claude Desktop / Claude Code 같은 AI 도구에 연결해요. 팩 카드의 연결 설정 복사를 눌러 나온 내용을 도구 설정에 붙여넣으면 끝이에요. AI는 팩을 읽기만 할 수 있어요.

Claude Desktop에 붙여넣는 방법
  1. 아래 팩 카드에서 연결 설정 복사 (JSON) 클릭
  2. Claude Desktop → 설정 → 개발자 → 설정 편집으로 설정 파일 열기
  3. "mcpServers" 항목 안에 복사한 내용을 붙여넣고 저장
  4. Claude Desktop 재시작 — 대화에서 팩 내용을 물어보면 확인됩니다

병합 — 같은 개념 합치기

같은 개념이 다른 이름으로 두 번 들어왔을 때 (예: "RateLimiter"와 "Rate Limiter") 하나로 합쳐요. 스캐너는 후보를 제안만 하고, 합칠지 말지는 항상 직접 정해요. 아니라고 한 쌍은 다시 물어보지 않아요.

대기 중인 병합 후보가 없어요. 중복 스캔을 눌러 찾아보세요.
