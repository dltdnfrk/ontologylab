        논문 소스 — API 키 미연결

        키는 macOS 키체인에 암호화되어 저장되며 data/ 어디에도 값이 남지 않습니다. 목록에는 다시 나타나지 않으며 연결됨/미연결 상태만 표시합니다. 출판사는 키가 없으면 응답하지 않습니다(전문 불가). 공개 API는 키 없이도 사용할 수 있지만 익명 한도를 공유하여 429가 자주 발생합니다.
